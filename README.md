# Rustfall

An original 8-bit style run-and-gun by Hullander Games. Play in the browser:
**https://hullander28.github.io/rustfall/**

- Works on iPhone/iPad (Safari → Share → Add to Home Screen for full-screen play), Android and desktop.
- Sign in with Google or email to sync progress, post to the leaderboard and play online co-op (2 players, 4-letter room code).

This repository contains the compiled web build (Godot 4.3, Compatibility renderer).
